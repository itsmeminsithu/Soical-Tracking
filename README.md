# Soical-Tracking

Started as an Instagram story viewer: a Node.js + Express backend talking to the Instagram Graph API, with a React + Vite frontend.

## Status

This repo is a skeleton, not a working app. At the moment it only has `index.tsx`, a webpack workflow under `.github/workflows/`, and the licence file. There is no backend, no frontend app, and no `package.json`, so there is nothing to install or run yet.

Keeping it here as the starting point. It stays on hold until I either restore the full source or archive the repo — I have not decided yet.
